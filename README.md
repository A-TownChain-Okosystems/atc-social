## Overview

The `atc-social` module forms a core pillar of the A-TownChain ecosystem under specification **ATC-45**. It provides full-featured ATCLang implementation for key infrastructure capabilities across `L7 — Social`.

## Modules Summary

- **`chat/chat_system.atc`**: P2P Chat — Direct messages, group chat, encrypted channels
- **`feed/social_feed.atc`**: Social Feed — Posts, likes, comments, follows, curation
- **`identity/social_identity.atc`**: Social Identity — Profile, avatar, bio, on-chain identity
- **`reputation/reputation_system.atc`**: Reputation System — Score, badges, endorsements
- **`messaging/messaging.atc`**: Messaging — Notifications, announcements, DM routing
- **`moderation/moderation.atc`**: Moderation — Content policies, reports, appeals, bans

## Getting Started

1. Ensure the ATCLang toolchain v0.3+ is installed.
2. Clone this repository into your workspace.
3. Import modules into your ATCLang entrypoints.
